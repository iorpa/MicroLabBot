A Telegram bot designed to help UIU students practice MCQs for the Microprocessor, Microcontroller and Interfacing Laboratory / Microprocessors and Microcontrollers Laboratory course.
## How to Use

1. Open Telegram and search for **micro_lab_practice_bot**.

2. Start the bot by clicking **Start** or sending:/start
   

3. The bot will show available options for practicing MCQs.

4. Select a topic or start an MCQ practice session.

5. Answer each question by selecting the correct option.

6. The bot will immediately show whether your answer is correct and provide the correct answer if needed.

7. Continue practicing to improve your preparation for the **Microprocessor, Microcontroller and Interfacing Laboratory / Microprocessors and Microcontrollers Laboratory** course.

## Features

- Practice MCQs from laboratory sheets
- Instant answer verification
- Helps UIU students prepare for lab exams
- Simple Telegram-based interface
- Available anytime for practice
